# 疑字判定：子代理提示词与结果格式

`ai-judging.md` 第 2 步给每批开一个全新子代理时，把下面的模板填好整段发过去。尖括号是要替换的地方；
「本书注意」一节只写这本书扫描件已知的特殊情况（见 `ai-judging.md`「各书实例」），没有就删掉这一节。
结果格式是 `merge_judgement.py` 与 `apply_judgement.js` 读的，字段名不要改。

## 模板

```text
你在校对一本历史教材的 OCR 结果。书名：<书名>。

材料在 <输出目录>：
- manifest.json：疑字清单。每条有 n（编号）、kind（disagree 两家读法不一致 / low 两家一致但把握低）、
  page（书上页码）、context（前后文，疑字用 ** 标出）、minerU（正文现在的字）、ocr（PaddleOCR 读的字）、
  line（整行截图）、zoom（单字放大图）。
- sheet-<起>.png 到 sheet-<止>.png：每张拼 5 个，左边红字编号，中间整行，右边放大。
你负责编号 <起号> 到 <止号>，共 <个数> 个。

逐个看拼图里的原书图像，判断正文该是什么字：
- 以图上印的字为准，上下文只作辅助，不要凭文意猜。（曾有凭上下文把原书印的「觶」猜成「觿」的错。）
- 拼图看不清时，再单独打开那一个的 zoom 图；看得清就别开，省额度。
- kind 为 low 的两家读法相同，多是认对的生僻字。
- 结论四选一：A 正文现在的字对；B PaddleOCR 读的对；C 两家都不对（写出原书实际的字）；D 图上看不清。
- 每条给把握：高 或 低。拿不准就写低，交给人判，不要硬判。
- 原书印的是繁体、异体或类推简化字形，而正文已是规范字：判 A，依据里注明。
- 正文不是规范字、原书印的是异体（如原书印「𫩫」，正文被读成「呎」）：判 C，correct 写规范字，
  再加 variant: {"printed": 原书字形, "standard": 规范字}；原书字形不在 Unicode 里时 printed 写部件式（如「⿰口厌」）。
- 原书本身印错了、正文照录：判 A，再加 misprint: 疑当作的字。

本书注意：<这本书扫描件已知的情况，如「入」看上去像「人」、「剌」「刺」分辨不出——这类只判把握低>

把结果写成 <输出目录>/judgement-b<批号>.json：一个数组，每个编号一条，格式见下。
写完只回复一行计数，如「b<批号>：<个数> 条，A x / B x / C x / D x，把握低 x」，不要贴表格。
```

## 结果格式（每条）

```json
{
  "n": 12,
  "page": "p.54",
  "minerU": "签",
  "ocr": "笈",
  "verdict": "B",
  "confidence": "高",
  "reason": "原图竹字头下为及，即笈多之笈",
  "correct": "笈"
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `n` | 是 | manifest 里的编号 |
| `page` | 否 | 书上页码，照抄 manifest，方便人看 |
| `minerU`、`ocr` | 是 | 照抄 manifest |
| `verdict` | 是 | `A` / `B` / `C` / `D` |
| `confidence` | 是 | `高` / `低`；只有「高」的 A/B/C 会被自动执行 |
| `reason` | 是 | 一句依据，写进校勘账本的「判定与依据」 |
| `correct` | C 必填 | 原书实际的字（异体时写规范字）；原书该处本无字、是 OCR 多读出来的（如混进正文的书口页码），写空串 `""`，执行时删去 |
| `variant` | 否 | `{"printed": 原书字形, "standard": 规范字}`，按用户选的 `variants` 决定正文用哪个 |
| `misprint` | 否 | 原书误植时疑当作的字；正文照录原书，另出校记 |
| `note` | 否 | 额外的校记文字 |

`merge_judgement.py` 合并时会核对：每个编号恰好一条、必填字段齐全、`verdict` 与 `confidence` 取值合法、判 C 写了 `correct`。
不合格就列出问题、不写 `judgement.json`，这时让那一批的子代理补齐再合并。
