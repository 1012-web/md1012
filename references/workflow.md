# md1012：两条工作流

以页面是否现代重新排印为主要分流依据，横竖排与文字层质量用于各流程内的技术选择。两条流程都采用 AI 读目录原图辅助建立多级标题。

```mermaid
flowchart TD
    A[PDF 或已有整理结果] --> S{确认本次任务范围}
    S -->|新建整本或分段整理| T{页面来源}
    S -->|已有结果或局部目录检查| L[复用已有材料<br/>记录 A 或 B 归属]
    L --> C
    T -->|论文、现代重新排印出版物| M[工作流 A<br/>含研究专著与现代点校古籍]
    T -->|旧刻本、旧刊本、抄本原页影印| H[工作流 B<br/>非现代排印古籍]
    M --> MP[优先利用 MinerU 原生结构<br/>恢复正文、脚注、图表与页码]
    H --> HP[按页识字与转录<br/>保留页序、原页码或叶码]
    MP --> C[AI 看目录原图<br/>提出候选标题树]
    HP --> C
    C --> B[核对正文题名、页码与父子关系<br/>应用多级标题，保留未判项]
    B --> R{本次是否还需文字核对}
    R -->|是| Q[第二读者比对，回原图核字]
    R -->|否，只做目录候选或对应检查| D
    Q --> V{按分支验收}
    V -->|A| MA[完整注释和图表核查<br/>通常逐行定位]
    V -->|B| HA[页码、多级标题、文字核对<br/>默认只需页级定位]
    MA --> D[校注、脚本改动报告与交付]
    HA --> D
```

此图给出可选阶段，实际只执行本次请求范围。局部目录候选检查可以复用现有图像和正文，交付候选及对应结果就结束，不以解析、核字、映射或改文为前置。

目录不存在时，AI 根据正文显式标题形式提出层级，注明依据；不伪造目录。目录未列细标题、目录与正文异名、缺题或缺页分别处理，见 [toc-headings.md](toc-headings.md)。

现代竖排排印本仍走 A；现代出版的影印集未重新排字则走 B。混合材料可分段记录。A 的结构若部分失效可换识字来源再核出版物结构；B 不要求建立一套通用版面引擎。没有做的文字/标题核查如实列明。
