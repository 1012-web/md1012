# AI 看原图判定疑字：两条工作流共用

只在本次任务需要文字校订时做；只读比较不自动升级成正文改写。已有授权和本书字形方针不重复询问；批量看图另有费用且尚未获得授权时，按范围估算并说明。页级映射足够用于整页核字，不要求古籍先完成逐行重建。

## 输入与比较

以最新正文、原 PDF 和实际第二读者缓存为输入。`minerU` 是旧格式字段名，表示正文当前读法；`ocr` 表示本条 `reader` 指定的第二读者，可以是 VL、看典或 MinerU，不能统称 VL。

```powershell
python -X utf8 scripts/vl_compare.py --book <书> --line-map <映射.json> --kandian "<看典目录>|21" --pages 21-30 --out <判定目录>
python -X utf8 scripts/doubt_sheets.py crops --book <书> --pdf <原 PDF> --doubts <判定目录>/doubts.json --out <判定目录>
```

选择 VL 时换成 `--vl-dir <VL目录>`；选择 MinerU 时换成 `--mineru "<输出目录>|<原PDF起页>"`，三选一。字形表自动读本书 config；明确 `--variant` 时覆盖。比较入口验证正文哈希，`--pages` 只统计本次范围，覆盖不完整退出码 2。详情见 [quality-and-location.md](quality-and-location.md)。

每条疑字带 `reader`、`sourceHash`、正文 UTF-16 偏移与页/行位置。截图校验正文版本；逐行映射可截整行/整列，页级映射或无框时截整页。使用原 PDF，而非页码起点不同的抽页小 PDF。

## 看图、合并和执行

1. AI 根据原图判断每条疑字，上下文只作辅助。需要批量并行且已获授权、环境支持子代理时，可按批使用 [judging-prompt.md](judging-prompt.md)；少量疑字可在当前对话完成。保留实际判定者，不虚构人工核验。
2. 判定 A 表示正文对；B 表示所选第二读者对；C 表示两家都不对，写原图实际读法；D 表示看不清。低把握不动正文，需要用户拍板时在对话中展示原图。
3. `merge_judgement.py <判定目录>` 检查缺号、重号与字段，再审阅分组。相同“原字→改字”可分组展示，但每个具体位置仍需有图像依据，不能只看一例就替换全书。
4. 获授权的正文校订使用下面命令，校注另存。原件误印判 A 并记 misprint；未获许可不把原件本身改成应有文字。

```powershell
python -X utf8 scripts/apply_doubts.py --book <书> --dir <判定目录> --variants keep
```

`keep` 保留已核原书字形，`normalize` 按用户已确定的规范写法并记原字。`--skip` / `--skip-file` 用于待整体处理的条目。

## 重跑与版本

脚本保留原始快照、`backup/` 和 `apply-state.json`。同一批相同判定重跑不会重复插字；原来 pending 的项后来确认，可以在同一批累计执行，仍基于原始位置。已执行判定改写、正文被外部编辑、manifest 换批次时停止，不猜新位置。此时先重建映射、疑字和裁图到新目录；旧的无 sourceHash 清单同样重新生成。

不要删执行状态后重用旧清单。结构、标题或正文在判定前改变，先刷新映射；执行后重新生成以后还要使用的映射。由 `diff_report.py` 对原稿/原生输出出报告，不能用 apply-report 代替所有阶段的全文比对。

整本流程可先改结构再做最新映射与核字，或先执行当前有效批次再改结构；重要的是不在生成偏移与应用之间改正文。现代出版物的脚注等结构另按工作流 A 检查；古籍 B 默认不扩展复杂注释工程。

## 花费与能力记录

历史批次的看图量：单字/拼图判定曾约每条 1600–2100 tokens；竖排补标点曾约每段 5200 tokens。它们不是当前模型的固定价格或免费额度，整页图和新模型应按实际试样修正。只在真的要启动额外付费批次时给出估算，不把询价变成所有局部任务的前置访谈。

模型和第二读者都会误读异体、专名和原刊误印。没有足够原图依据时保留 pending；Unicode 未收字形可用部件式或原图记录，具体正文取舍交用户，不强行背离已选字形方针。
