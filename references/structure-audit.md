# OCR 底稿的结构核查：注、篇题、清单页、残留

在 SKILL.md 或 vl.md 指到这里时读。适用于以 VL 作底稿的书；MinerU 底稿但有页下注和目录的古籍也值得做一遍。

**开工时就告诉用户这一步的范围和花费**，让用户选做到哪一档（没做的写进交付报告）：

1. 目录与篇题：清单页、目录整页重录，目录对篇题（第 2、3 步）。
2. 再加注区逐页核对与补注（第 4 步），花费随有注的页数增长。
3. 再加残留扫描与计数复查（第 5、6 步）。

**没有页下注的书**（注是段内夹排的小字，如《明通鉴》的【考異】）不做第 4 步；`vl_build.py` 报告的 `_ruleWithoutNotes`
（测到细长线却没认出注的页）多是专名线，抽几页看原图确认即可。

**为什么要单独做**：疑字比对只比字、不管结构。一条整条漏收的注、一个整行读丢的篇题，比字看不出来。《黄道周集》（497 页）在 501 处疑字判定做完之后，结构核查又查出：

- 61 条注整条漏收，多数混在正文里；
- 2 条注是两注并成一条；
- 17 个篇题读丢；
- 3 段清单页漏读约三分之二；
- 若干书眉、注号残字、空白页上编出来的字混进正文。

「可信、高质量」的 Markdown 要求脚注、页码、多级标题都齐全，这一步省不得。

脚本是 `scripts/structure_audit.py`（各子命令用法见文件开头）。给子代理的提示词模板在 [structure-prompts.md](structure-prompts.md)，派子代理时再读。

它读书配置 `<书>/_数据/config.json`，开工前先写好：

```json
{
  "pdf": "黃道周集.pdf",
  "markdownFiles": ["00-卷首.md", "01-目录.md", "02-前言.md", "03-正文.md"],
  "printedPageOffset": 98,
  "fileOffsets": ["00-卷首.md|0", "01-目录.md|9", "02-前言.md|16", "03-正文.md|98"],
  "writingMode": "vertical-rl",
  "variantEquivalents": ["黄黃", "説說"]
}
```

`fileOffsets` 是各文件「物理页 − 印刷页」（`vl_build.py pages` 的报告里给出），`variantEquivalents` 是本书字形表（原书字形在前，只收看原图核实过的）。

## 顺序（先后有原因）

1. **疑字判定的执行放在最前**。`apply_doubts.py` 按截图时的 UTF-16 偏移改字。先动结构，后面的偏移就全挪了。所以要么先执行判定再做结构核查，要么结构改完后重跑逐行映射与比对、重新截图。判定时标为「这是混进正文的注文」「这页要整页重录」的编号，执行时用 `--skip` 跳过，留给下面的步骤整段处理。
2. **目录、清单页整页重录**。VL 读目录式页面（篇名 + 引导点 + 页码，或按文体分列的篇目清单）最容易出错：篇名和页码粘连、条目漏读、文体标签丢失、夹进书眉。修补不如照原图重录（提示词模板「清单页重录」）。
   - 目录要先重录，第 3 步拿它对篇题；
   - 重录后与旧稿比条数，差得多就说明旧稿漏读了；
   - 重录稿里的字形按本书字形表统一。子代理常把「黄」写成「黃」，要改回原书字形。
3. **目录对篇题**：
   - `toc-check` 列出正文里找不到的篇题，同时列出正文有、目录没有的标题（可能是误升成标题的普通文字）；
   - `tasks --kind titles` 出任务，子代理看图给出插入位置（模板「按页改动」），然后 `apply`；
   - 补篇题时一并补篇题後的小字日期，以及粘在别处的文体标签。
   - 目录与正文标题用字可能不一致（SKILL.md「探查与审计」），报缺时先看是不是用字差异。
4. **注区核对**：
   - `notes-sheet` 按分隔线裁出每页注区，配上 Markdown 里记在这一页的注；
   - 子代理逐页对照（模板「注区核对」），写 `audit-*.json`；
   - `tasks --kind notes` 出补注任务，每条漏收的注给一个临时编号（9001 起）；子代理看图定位注号、指出混进正文的注文，写成按页改动；
   - `apply --book-forms`：新注文按本书字形表改成原书字形，只在异体字方针为「保留原书字形」时加这个参数。
   - 并条（两注并成一条）量少，手工拆开：新注用 8001 起的临时号，注号位置看图。
5. **残留扫描**：`tasks --kind residue` 扫出注号残字（「（一）」「〔三〕」「「一」」「<!--?fnref-->」）和书眉（`--running-head` 传页脚印的篇名，可传多个），子代理逐处看图（模板「按页改动」）。扫出的多半是正常文字，比如引文里的「七」「九」、正文里本来就有的篇名，所以一定要看图判断，不能直接删。
6. **重编注号、复查**：
   - `renumber`：按注号在正文里出现的先后重编为 1..N。报告应为「无注号的注文 0、无注文的注号 0」；有的话逐条查。
   - `notes-count`：用第 4 步的核对结果复查每页注数。对不上的页多半是当初分隔线没测到、没进核对清单的页，要看图补查。
7. **重跑映射、文字层、索引**。映射报告里的 `unmappedBlocks` 逐块看，结构问题常藏在里面。《黄道周集》里就有一个块是空白页透印读出来的「二」。

## 结果格式

注区核对（每页只报不一致，没问题写 `[]`）：

```json
{"pdfPage": 22, "type": "missing", "local": 2, "after": 13, "text": "《黄漳浦集》卷三十六。"}
{"pdfPage": 25, "type": "merged", "label": 17, "parts": ["參見《明史》卷二百五十一《文震孟傳》。", "《救鄭鄤疏》，《黄漳浦集》卷二。"]}
{"pdfPage": 30, "type": "extra", "label": 22, "reason": "…"}
```

按页改动（补注、补篇题、清残留共用；`apply` 执行）：

```json
{"file": "02-前言.md", "printed": 6,
 "edits": [{"find": "作《九盭傳》「一。", "replace": "作《九盭傳》」[^9001]。"},
           {"find": "<small>〔二〕《黄漳浦集》卷三十六。</small>", "replace": ""}],
 "newNotes": [{"label": "9001", "text": "《年譜》。"}]}
```

- `find` 必须在这一页的正文段（本页锚点到下一个锚点之间）里恰好出现一次。一页里任何一条对不上，整页不动，列进 `apply-report.json`，交回子代理修正定位串再跑。
- 删除就是 `replace` 为空串。插入篇题：`find` 取篇题位置之前的一串字，`replace` 为「那串字 + `\n\n### 篇题[^注]\n\n`」。

## 坑（《黄道周集》实测）

- **分隔线没测到的页不进核对清单**：物理 28、35 页有注，但当初没测到线，Markdown 里也没有注。靠第 5 步的残留扫描和第 6 步的计数复查才补上。
- **扫描件本身坏了的页**：物理 35 页下半截整体错开约一栏。上下半截在前半页能接通，到后半页不论怎么配都有冲突。这种页不要硬拼，正文里加 `<!--? 原扫描件本页下半截错位，正文次序待对纸本重排-->`，列进待办交用户对纸本。
- **空白页与透印**：VL 会从空白页的背面透印里读出字；书口的页码也会被读进正文（「……刊刻六七」）。
- **`<small>` 误标**：正文字号的奏首（「原任……謹奏：爲……事。」）被标成小字；反过来，卷末的小字校字题名又没标。看图改。
- **篇题读丢时，挂在篇题後的注号也一起丢了**。先补篇题，再挂注号：`tasks --kind notes` 里这类注的 `after` 会写 null，跳过这页，补完篇题再处理。
- **子代理的附带提醒要跟进**：比如「整段正文被错包成 `<small>`」「篇题後的小字日期也丢了」「文体标签粘在上一篇末尾」。这些不在任务范围内，只在回报里提一句，主会话要逐条处理。
