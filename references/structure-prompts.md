# 结构核查：子代理提示词模板

[structure-audit.md](structure-audit.md) 的各步派子代理时，把对应模板填好整段发过去。尖括号是要替换的地方。

共同的做法：

- 每批一个全新子代理，几批同时跑；
- 结果只写进文件，回报只要一行计数，免得撑满主会话；
- 子代理要用 Python 自己核对定位串唯一，再交结果；
- 「本书字形」一句按这本书的异体字方针写。方针为保留原书字形时，列出本书字形表里容易写错的几个，如「本书印『黄』『録』『説』『爲』『内』，不印『黃』『錄』『說』『為』『內』」。

## 注区核对

```text
你在核对一本<竖排/横排>古籍整理本（<书名>）的页下注是否完整。

材料在 <书>/_数据/注区审核：
- manifest.json：每页一条：pdfPage、image（该页注区的裁图）、sheet（拼图名）、
  notes（Markdown 里记在这一页的注，按顺序：label 是全文件的注编号，text 是注文前 60 字，file 是所在文件）。
- sheet-N.png：每张拼 4 页的注区，红字「PDF 页号」标在每页旁。看不清时再开单页的 pNNNN.png。
你负责 sheet-<起> 到 sheet-<止>。

原书每页的注在分隔线<左侧/下方>，每条以〔一〕〔二〕……开头（本页内编号）。
逐页核对：图上本页有几条注、每条开头是什么；与 notes 逐条对照。只报不一致：
- missing：图上有、notes 里没有的。写出本页第几条（local），并完整抄录注文（照原书字形，不含〔N〕号）。
- merged：notes 里一条实际包含图上两条（常见形如「……。《二》……」「「一」……」）。写出 label，以及拆开后的两条注文。
- extra：notes 里有、图上没有的。
- wrongText：notes 的开头与图上明显不同（整条对错了注，不是个别字的差异）。
个别字的差异不用报（另有流程逐字校）。本书字形：<…>

结果写成 <书>/_数据/注区审核/audit-a<批号>.json（UTF-8），一个数组，每个问题一条（格式见下），没有问题写 []：
{"pdfPage": 22, "type": "missing", "local": 2, "after": 13, "text": "……"}
{"pdfPage": 25, "type": "merged", "label": 17, "parts": ["……", "……"]}
写完只回复一行：「a<批号>：核了 x 页，问题 y 条（missing a / merged b / 其他 c）」。
```

## 按页改动（补注 / 补篇题 / 清残留）

`tasks.json` 每页有：file、printed、pdfPage、image（整页图）、segment（该页正文段，逐字照抄自文件）、pageNotes（该页已有的注）、items（这页要处理的项）。三种任务共用一个模板，只换「要做的事」一段。

```text
你在修一本<竖排/横排>古籍整理本（<书名>）Markdown 的结构问题。

材料在 <任务目录>/tasks.json；你负责 pdfPage 在 <起> 到 <止> 之间的页。每页的 image 是整页原图<（竖排，从右往左读）>。

要做的事：<从下面三段里选一段贴在这里>

规则：
- 以原图为准，每处都看图。正文本身的字一个都不能改（个别错字另有流程），只处理结构问题。
- 改动写成 edits：[{find, replace}]。find 照 segment 原样逐字抄（含标点与 Markdown 记号），
  在 segment 里必须恰好出现一次；删除就是 replace 为空串。同一页的几条 find 不能互相重叠。
- 本书字形：<…>

结果写成 <任务目录>/result-<批号>.json（UTF-8），每页一条：
{"file": "…", "printed": 6, "edits": [{"find": "…", "replace": "…"}], "newNotes": [{"label": "9001", "text": "…"}]}
写完用 Python 核对每个 find 在对应 segment 里恰好出现一次。
只回复一行计数，再加一句需要主会话注意的情况（没有就写无）。
```

**补注**（`--kind notes`，items 是 `{label, local, text}`）：

```text
items 里的注是这一页漏收的注（label 是临时编号，text 已抄好）。OCR 常见的乱法：注文被当成正文混进 segment
（有时包在 <small> 里、有时接在段尾、有时连同注号「〔一〕」「（一）」「一」一起），正文里原书的注号丢了或读成残字。
1. 看图找到每条注的注号〔N〕在正文里紧跟哪几个字，把 [^label] 插在那里（有注号残字就连残字一起替换掉）。
2. 删掉混进 segment 的注文（整段 <small> 都是注文就连标签一起删）。
3. 把 items 里的注照抄进 newNotes（label、text 不变）。
4. 注号位置因篇题整行读丢而没处挂的，这页不写结果，在回报里说明。
```

**补篇题**（`--kind titles`，items 是 `{title}`，已按目录核准）：

```text
items 里的篇题在这一页被 OCR 读丢了，或读成乱字混进了正文。看图确认位置（前面通常是上一篇的结尾，后面是本篇奏首或正文），
用 edits 把它插成单独一行：find 取篇题位置之前的一串字，replace 为「那串字 + \n\n### 篇题\n\n」；篇题若在本页最前面，
find 取本页正文的开头几字，replace 为「\n\n### 篇题\n\n + 那几字」。篇题後原书小字的日期写成「### 篇题 <small>日期。</small>」。
篇题被读坏的残字、粘在上一篇末尾的文体标签（「……之至！表」）一并处理；文体标签单独一行写成「## 表」。
```

**清残留**（`--kind residue`，items 是 `{hits}`：脚本扫出的可疑字串）：

```text
items 的 hits 是脚本扫出的可疑字串，多半是正常文字，每处都要看图判断：
- 书眉混进正文（原书页脚印的篇名，常紧挨 <!--p.N--> 锚点）→ 删；正文里本来就有的同样字句不动。
- 注号残字（「（一）」「〔三〕」「「一」」）：图上是注号时，pageNotes 里有这条、正文没有它的 [^label] → 换成 [^label]；
  pageNotes 里没有（漏收了）→ 换成 [^6<页码><序号>] 并在 newNotes 补注文。图上不是注号（小节号、引用的数字）→ 不动。
- 注文混进正文 → 删；pageNotes 里没有的照上一条补。
- 几种文字拼在一起的碎段 → 看图拆清楚：属于注的归注，属于书眉的删，属于正文的留在原位。
```

## 清单页重录（目录、篇目清单、书目部次）

```text
任务：照原书图像重新录入一本<竖排/横排>古籍整理本（<书名>）里的几页<目录/篇目清单>。OCR 旧稿错乱、漏了条目，只可作参考，一切以原图为准。

材料在 <书>/_数据/<目录重录|清单重录>：pdf<N>.png（原图<，竖排从右往左读，常分上下两栏：先上栏从右到左，再下栏>）、old-*.md（旧稿）。

输出 new-<范围>.md（UTF-8）：
1. 每页开头单独一行页码锚点 <!--p.N-->（印刷页码），前后空一行。跨页的条目放在它开始的那一页。
2. 大标题写 `# …`；分部、卷名、文体标签（初部、卷一、疏、論、書……）单独一行写 `**疏**`；原书怎么分就怎么分，不自造分部。
3. 每个条目一行：目录写 `- 篇名　作者 …… 页码`（篇名与作者之间一个全角空格，页码照原书汉字数字）；
   篇目清单写 `- 篇名`，篇名後的小字注（「二篇」「闕」「又見《…》」）写 `<small>…</small>` 紧跟篇名。原书折行的篇名合成一行。
4. 页眉页脚的书眉、页码不录。正文里的注号〔一〕写成 Markdown 脚注 [^7<页码>]，注文另写 notes.json：[{"label", "page", "text"}]。
5. 字形照原书印的抄；本书字形：<…>。标点照抄。
完成后逐页对照图自查，条目一条不漏、页码递增（不递增的回图上再核，确是原书如此就照录）。
只回复一行「重录完成：x 条」，再加一句拿不准的字（没有就写无）。
```

重录稿换进正文：用它替换旧稿里从起始页锚点到结束页下一个锚点之间的内容，notes.json 的注文并进注释节，再跑 `structure_audit.py renumber`。
